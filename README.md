# Academic GPA/GWA Ledger & Analytics System 🧮

A robust, native desktop performance utility designed to help university students track, model, and evaluate their Cumulative Grade Point Average (GPA) and General Weighted Average (GWA). Built natively using Java, this application prioritizes clean user interaction layouts and features dynamic interface runtime modifications.

## 🌟 Premium Features
- **Precise Credit-Weight Computation:** Uses absolute academic weight formulas to compute semestral weighted averages seamlessly without mathematical rounding drift.
- **Dynamic Interface Theme Toggling:** Features a built-in state modification routine (`toggleTheme()`) that instantly re-allocates color matrix maps across interactive panels, fields, and text headers.
- **Relational Ledger Persistence:** Implements localized file tracking frameworks (`student_grades.txt`, `gwa_data.txt`) to securely write, manage, and read historical semestral records.
- **Typographic Layout Architecture:** Utilizes structured layout constraints and input verification loops to deliver clean, modern margin alignment properties.

## 🛠️ Technical Specifications
- **Core Engine / SDK:** Java Development Kit (JDK 17 - Temurin Architecture)
- **GUI Engine Framework:** Java Swing (`JFrame` Application Structs)
- **Data Persistence:** Local Structured File Database Routing
